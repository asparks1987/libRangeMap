# Changelog

## 0.1.0-alpha

- Rebuilds the project around the dependency-free Alpha v1 integer mapper.
- Changes the default output range to `[-1.0, 1.0]`.
- Adds strict and clipping out-of-range behavior.
- Adds JSON-compatible mapper serialization.
- Adds standard-library unittest coverage.
- Documents legacy behavior and beta roadmap.
