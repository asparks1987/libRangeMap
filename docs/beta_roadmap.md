# Beta Roadmap

Beta expands the alpha integer mapper into a broader dependency-free mapping SDK.

Before beta, Alpha should prove the cross-language architecture with a first-party C core, stable C ABI, and thin wrappers for the declared Alpha language targets.

Planned beta work:

- mapper and adapter interfaces
- float mapper
- character and text mappers
- bytes and buffer mappers
- sequence and nested sequence mappers
- raw pixel data mappers without image-library dependencies
- custom object schemas
- language-neutral compliance fixtures
