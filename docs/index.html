canonical contract

Built for reproducible pipelines.

Alpha v1 focuses on integer range mapping. Additional value types are planned after the language-agnostic runtime target is complete.

Deterministic

Same input plus same config always produces the same output.

Dependency-free

The core SDK and wrappers avoid third-party runtime packages.

Explainable

Ranges, output bounds, clipping, and specs stay visible and serializable.

mapped = out_min + ((value - in_min) / (in_max - in_min)) * (out_max - out_min)
