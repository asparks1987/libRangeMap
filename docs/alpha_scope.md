# Alpha Scope

Alpha v1 ships one stable primitive: `IntegerRangeMapper`.

It maps finite integers from a declared integer range into a floating-point output range. The default output range is `[-1.0, 1.0]`.

Deferred until beta:

- floats
- characters
- strings
- bytes and buffers
- nested sequence mappers
- raw pixel/image-like mappers
- custom object schemas
- multi-language packages
